# Unique Value Proposition

For informal e-waste collectors who lose value through fragmented demand,
uncertain routes and weak proof at handover, Kabadiwala Connect is a
collector-first field workbench that shows whether a verified formal route is
actually worth taking, lets multiple collectors opt into one demand threshold,
and carries a signed, reviewable material record through offline interruptions.

The first memorable action is not “see a price”; it is “compare net route,
pool only with consent, and settle with evidence.”

This is a prototype value proposition. It does not claim verified adoption,
better prices, official recycler status, environmental impact or ML accuracy.
